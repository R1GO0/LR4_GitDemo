# Лабораторная работа №4 — Git и GitHub

Демонстрационное Windows Forms приложение на C#.

## Запуск
Откройте `LR4_GitDemo.csproj` в Visual Studio 2022 и нажмите F5.

## Возможности
- Главная и вторая формы;
- переход между формами;
- кнопка-счётчик на второй форме;
- проект подготовлен для работы с Git (`.gitignore`).

## Проверка Git
Создайте коммиты, ветку `AddFunction`, внесите в ней изменение, затем выполните слияние в `master`.
